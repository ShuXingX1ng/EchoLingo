# EchoLingo Development Rules

## Project Context
EchoLingo is an IELTS speaking practice platform.

Tech stack:
- Next.js
- TypeScript
- TailwindCSS
- DeepSeek API

## Workflow

Before coding:
1. Read docs/PROJECT_CONTEXT.md
2. Read docs/TASKS.md
3. Read docs/DEVELOPMENT_LOG.md

After coding:
1. Update DEVELOPMENT_LOG.md
2. Update TASKS.md
3. Explain changed files

## Coding Rules

- Keep components modular
- Avoid over-engineering
- Mobile-first design
- Prefer MVP implementations
- Avoid duplicate planning documents
