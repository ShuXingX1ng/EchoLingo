关键设计决策

决策 选择 面试时的理由
无 Router Agent 题型由调用方直接传入 taskType 始终已知，路由层没有实际判断价值，增加无意义复杂度
Azure PA vs Whisper Azure 做发音评分，Whisper 做转录 Azure 提供音素级别数据；Whisper 只有时间戳，发音准确度无法从时间戳推断
评分范围 10–90，对齐 PTE 官方维度 Reading/Writing 维度客观可测；Speaking 加「仅供参考」标注因 Pearson 权重不公开
RAGAS 适用范围 仅 Summarize Written Text RAGAS 需要 context；Write Essay 是开放写作，无 context 可算 Faithfulness
LLM-as-Judge 阈值 任意维度差值 > 15 分触发重评 规则简单可解释；分歧率从 XX% → XX% 是可量化的 prompt 优化指标
用户画像粒度 Task Type 级别 Section 级别聚合会丢失诊断信息：同一 Section 内不同 Task Type 考察完全不同能力
学习轨迹 缺口分析（对比用户目标分） 不预测绝对考试分数；用户设目标，系统显示各维度差距，更可操作
